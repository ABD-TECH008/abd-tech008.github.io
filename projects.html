Website Change Detector

Node.js · Playwright · Docker

What: A tool that watches public web pages and alerts you when something meaningful changes.

How: A headless browser (Playwright) loads each page on a schedule (15 minutes to 24 hours). Noise such as ads, timestamps and counters is filtered out before comparing, and changes are shown as text and screenshot differences. Alerts go out by email, Telegram, Discord or webhook, and the app runs in Docker.

Results: A working app deployed online. It ignores CAPTCHAs and outages instead of raising false alarms, and it avoids overloading websites by loading each URL only once per cycle.

AI Food Nutrition Tracker

React · FastAPI · PyTorch · SQLite

What: An app that recognises Indian dishes from a photo, adjusts nutrition values for portion size, and logs daily meals.

How: I led the team. A React (Vite) frontend talks to a FastAPI backend that uses a pretrained Hugging Face model, with meals stored in SQLite and nutrition values from the IFCT and USDA data. The team worked from a shared API contract.

Results: A working prototype with photo capture, a portion slider and a meal log. Voice search and activity tracking are being added, so this project is ongoing.

MasterTrack: Personal Finance Tracker

Python · Streamlit · SQLite3

What: A web app where users set a monthly budget and log daily expenses in rupees.

How: Built as a team of four with Python and Streamlit. My part was the SQL database design and connecting the back end to the front end. Passwords are stored hashed and each user sees only their own data.

Results: A working app with login, monthly budgets, 11 expense categories, a budget progress bar, and line, bar and pie charts.

Iris Flower Classification

Python · scikit-learn · Pandas

What: A machine-learning model that predicts the species of an iris flower from four measurements.

How: I split the data 80/20, trained a Decision Tree and a KNN classifier (k=5), and compared them using accuracy, confusion matrices and 5-fold cross-validation.

Results: KNN scored 100% on the test set (97.3% in cross-validation) and the Decision Tree 93.3% (95.3%). The Decision Tree’s only mistakes were between versicolor and virginica.
